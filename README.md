# LittleLua
A little and light lua wrapper.
Example1:
```lua
width = 42
height = 23
name = "Walter White"
numbers = { 1, 2, 3 }
fruits = { "pear", "apple", "banana", "pineapple", "berry" }

mytable = {
    name = "Alan",
    surname = "Donnor",
    age = 67,
    weight = 69.5,
    more = {
        food = "cheese",
        price = 2
    }
}
```
